# 入学测评与分班建议领域指南

## 业务问题

试听或入学测评后，分班常凭印象或销售目标决定，导致课程难度不匹配、转班和退费。

## 产品解决方案

结合测评结果、课程级别、时间约束和学习目标生成可解释的分班建议，并保留不确定性和人工确认。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `student_profile` | 学生基本情况 | 是 | 年级、学习经历与时间约束；须脱敏 |
| `assessment_results` | 测评结果 | 是 | 测评工具、分数与观察 |
| `course_catalog` | 课程与级别 | 是 | 课程目标、先修要求和适合对象 |
| `available_classes` | 可入班清单 | 是 | 班型、时间、教师、容量和余位 |
| `schedule_constraints` | 时间约束 | 是 | 学生与家庭可上课时段 |
| `parent_preferences` | 家长偏好 | 否 | 仅用于约束，不得替代适合度判断 |
| `capacity` | 容量规则 | 是 | 班额和超员边界 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

测评工具本身可能有误差；需要课程标准和教师确认；不能为了成单推荐不适合班型。
