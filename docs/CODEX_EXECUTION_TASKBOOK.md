- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`
- 候选来源：`CAND-022`
- 正式产品：`JLZ-EDU-SK-089` / 入学测评与分班建议
- 类型：Skill
- 批次：3
- 业务中心：11 学员成功与家庭服务中心
- 版本基线：`EDUCATION_BASELINE_V1.0.0`
- 产品版本：`1.0.0`
- 许可证：Apache-2.0

## 2. 用户、痛点与目标

- 用户：课程顾问、教务、教研教师、校区主管
- 痛点：试听或入学测评后，分班常凭印象或销售目标决定，导致课程难度不匹配、转班和退费。
- 目标：结合测评结果、课程级别、时间约束和学习目标生成可解释的分班建议，并保留不确定性和人工确认。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `student_profile` | 学生基本情况 | string | 是 |
| `assessment_results` | 测评结果 | array | 是 |
| `course_catalog` | 课程与级别 | array | 是 |
| `available_classes` | 可入班清单 | array | 是 |
| `schedule_constraints` | 时间约束 | array | 是 |
| `parent_preferences` | 家长偏好 | string | 否 |
| `capacity` | 容量规则 | string | 是 |

## 4. 工作流

1. 确认测评口径
2. 对照课程先修要求
3. 检查硬约束
4. 生成首选/备选班型
5. 说明风险
6. 设计衔接任务
7. 人工确认

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点学生年级、学习经历、测评结果、课程级别目标、可用时间、班型容量、家长偏好、教师观察，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕结合测评结果、课程级别、时间约束和学习目标生成可解释的分班建议，并保留不确定性和人工确认。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按确认测评口径 → 对照课程先修要求 → 检查硬约束 → 生成首选/备选班型 → 说明风险 → 设计衔接任务 → 人工确认设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由业务负责人复核输入事实、关键假设和最终成果适用范围。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `分班建议表`
- `依据`
- `硬约束冲突`

## 7. 差异化与排重

- 与现有产品：家长需求诊断关注购买动机；本产品是测评到班型匹配的操作决策，不承担销售说服。
- 排重检查：部分重叠；使用学生信息与测评，但输出分班建议与风险，不生成销售话术或完整排课。
- 独立理由：不依赖排课系统，可用班型清单和容量独立完成建议。

## 8. 安全与人工门禁

- 复核角色：业务负责人
- 复核范围：输入事实、关键假设和最终成果适用范围
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
